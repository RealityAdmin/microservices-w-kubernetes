# microservices-w-kubernetes
Toy project after last repo to make microservices using Go and use Kubernetes.

Specifically, after following Microservices with Go for a bit, I wanted to implement the tutorials from scratch, with minimal reference and redoing an assignment I did in uni.



## NOTES FOR SELF: RUNNING FROM SCRATCH
1. Start minikube
2. Apply deployments in folders
3. run minikube service orders-service --url to get main endpoint
